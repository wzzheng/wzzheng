### Current Interests

Our target now is to build **Physical Superintelligence (PSI)** systems on more general robots.

🦙 LLMs + 💻 Digital Harness  ->  🧠 AGI

🦙 LLMs + 🌍 Physical Harness (📐 Spatial Intelligence, 🌐 World Modeling, and 🦾 Embodied Robots)  ->  🤖 PSI

- 📐 Spatial Intelligence: generative geometry foundation models with complete geometry, motion, and semantics
- 🌐 World Modeling: world model agents with multimodal harness and embodied interaction control
- 🦾 Embodied Robots: humanoids with whole-body intelligence and dexterous manipulation ability
- 🦙 LLMs: recurssive self-improvement for multi-agent system, GUI agents and spatial agents
